# Python Data Types

## Overview

Python data types define the kind of value stored in a variable and determine how that value can be used and processed.

For practice, I created a small **Student Profile Analyzer** that uses different Python data types together.


## Basic vs Collection Data Types

**Basic data types** represent individual values, such as strings, integers, floats, complex numbers, and Boolean values.

**Collection data types** store multiple values within a single object. Lists and dictionaries are mutable, while tuples are immutable. Sets store unique values without maintaining a conventional sequence.

## Type Identification

Python's built-in `type()` function can be used to determine the data type of an object.
